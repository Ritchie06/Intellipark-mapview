03
Water Quality Monitoring System

A smart water quality monitoring system using Bayesian Change-Point Detection (BCPD) to continuously analyze water parameters such as pH, Turbidity, TDS, and Temperature. The system detects sudden changes in water quality, classifies water as safe or unsafe using WHO standards, and provides early warnings through email and voice alerts.

Key Features
  • Bayesian Change-Point Detection (BCPD) for anomaly detection
  • Multi-parameter analysis: pH, Turbidity, TDS, Temperature
  • WHO-standard water safety classification (safe / unsafe)
  • Real-time email & voice alert notifications
  • ANN model for accurate water quality prediction
  • Automated continuous monitoring pipeline

04
Intelli Park MapView

Intelli Park MapView combines grid-based pathfinding with cloud integration. It automatically detects available parking slots, computes the shortest path using the A* algorithm, and visually highlights the route on a parking layout using OpenCV. The generated layout is uploaded to the cloud and a QR code is produced so drivers can scan it and view the personalized parking map on their phones.

Key Features
  • Grid-based 2D parking layout with slot detection
  • A* Pathfinding Algorithm for optimal route calculation
  • Visual path highlighting using OpenCV
  • Sequential slot assignment for efficient parking
  • Cloud integration via ImgBB API for layout upload
  • QR Code generation for mobile viewing
